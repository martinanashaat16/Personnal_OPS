📁 Shared Excel Database (OneDrive)
All data is stored in one Excel workbook inside your shared OneDrive folder. Everyone who connects to the same workbook sees the same data, and changes made by other users appear automatically within a few seconds.
How to set it up
  1. Person who owns the data (once): click Create new Excel file and save it inside the shared OneDrive folder (e.g. HR_Data.xlsx). Your current data is copied into it.
  2. Everyone else: make sure the shared folder is synced to your PC (OneDrive → Add shortcut to My files / Sync), open this app in Chrome or Edge, click Connect to existing Excel file, and pick the same HR_Data.xlsx.
  3. Next time the app opens, click Reconnect in the yellow bar once per session (the browser asks for permission each time).
Please do not keep the workbook open in Excel while using the app — Excel locks the file and saves will wait until it is closed. Do not edit the hidden _AppData sheet; the Hires / Contracts / Offboarding / Overtime sheets are read-only reports.
